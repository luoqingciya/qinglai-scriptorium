# 清籁斋 v0.1.0

面向长篇小说与笔记的个人写作工作台。首个可安装版本，仅 Windows。

## 这是什么

**文件即真相。** 稿件是磁盘上的 Markdown + YAML front matter，不引入任何私有格式。
可以用任何文本编辑器打开，可以用 git 做版本管理，换工具时不需要迁移。

索引、缓存、双链、人物、统计全部是可丢弃的派生结构，损坏不会造成数据损失。

## 主要功能

**写作与数据安全**

- 所见即所得编辑，Markdown 为磁盘格式
- 原子写（tmp → fsync → rename），任何时刻崩溃都不留半截文件
- 崩溃恢复日志：强杀进程最多丢 150ms 输入
- 外部修改检测：磁盘文件被别人改过时不静默覆盖，明确提示冲突
- 删除进 `.trash/`，不物理删除

**章节管理**

- 新建、重命名、删除；同目录上下移排序
- 重排只改真正变化的文件，不会让整卷产生无谓 diff
- 段首缩进靠 CSS 渲染，存储层一个缩进字符都不写

**检索**

- 全库全文检索，字符二元组倒排，不依赖分词词典
- 多个关键词按「且」组合，结果带上下文摘要

**`[[双链]]` 与反链**

- 正文写 `[[章节名]]` 即可建立链接，支持 `[[目标|别名]]`
- 点击跳转；反链面板显示哪些章节引用了当前章
- 编辑器内高亮用 Decoration 实现，不改变文档结构，序列化零影响

**人物卡**

- 从每章的 `characters` / `pov` 自动汇总出场索引
- 视角人物自动算作出场；点角色展开出场章节

**大纲**

- 每章可写一行 `summary`，一屏看全书脉络
- 支持内联编辑

**导出 docx**

- 宋体小四、1.5 倍行距、首行缩进 2 字符、章间分页
- 直接构造 OOXML，不走 HTML→docx（那条路对中文缩进不可靠）
- 双链语法自动还原成纯文本

**其他**

- 写作统计：每日字数趋势，今日增量
- 三套主题：暗色 / 亮色 / 护眼
- 专注模式（F11）：隐藏目录树，编辑区铺满

## 安装

下载 `清籁斋_0.1.0_x64-setup.exe`，双击安装。

安装到当前用户目录，**不需要管理员权限**。

## 首次使用

1. 点左上角「打开稿库」，选一个目录（或新建一个空目录）
2. 点「新建」写下第一章
3. 稿子就是这个目录里的 `.md` 文件

也可以直接打开仓库里的 `examples/sample-vault` 看示例。

## 已知限制

- 仅 Windows（x64）
- 不做多设备同步，数据只在本地
- 软换行（段内 Shift+Enter）会被规范化成行尾反斜杠，内容不丢
- 图片、表格不导出到 docx
- 单章超过 10 万字未做性能验证

## 数据位置

稿件：你选择的目录，`.md` 文件。
写作统计：稿库内 `.qinglai/stats.json`（丢了不影响稿件）。
删除的章节：稿库内 `.trash/`。
