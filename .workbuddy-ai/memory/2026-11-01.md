**核心设计前提（已写入 docs/architecture.md）**：文件即真相，索引可重建。

### 已确定的技术选型

- 编辑器：Milkdown 7.23（所见即所得，remark + ProseMirror，Markdown 为真相源）
- 前端：React 19 + TypeScript + Vite 6，状态用 zustand

- 首版重心：长篇小说

### 踩到的坑（后续会再遇到）

1. **`@milkdown/react` 7.23 内部锁 `@milkdown/kit@7.22.3` + `@milkdown/crepe`**，版本耦合严重。
   已弃用，改为 vanilla `Editor` + 自写 hook（`src/features/editor/useMilkdown.ts`）。
   **所有 milkdown 包必须钉死同一版本**。
2. **pnpm 11 把构建脚本白名单从 package.json 迁到 `pnpm-workspace.yaml`**，
   否则 `pnpm tauri` 会因 `ERR_PNPM_IGNORED_BUILDS`（esbuild）失败。
   临时绕过：`./node_modules/.bin/tauri <cmd>`。
3. **walkdir 的 `filter_entry` 会作用于根目录**。`tempfile::tempdir()` 目录名以 `.tmp` 开头，
   隐藏目录过滤规则把根目录也杀了，导致 5 个扫描测试全挂。修法：`entry.depth() == 0` 直接放行。
4. **vitest 2 + Vite 6 类型冲突**：`vitest/config` 的 defineConfig 绑 Vite 5 的 Plugin 类型。

### 关键实现决策

- **front matter 字节永不漂移**：`md::split` 返回 `head`（文件开头到闭合分隔行的原文），
  `replace_body` 直接 `head + new_body`，不重新序列化 YAML。
- **打开但不编辑 → 不写盘**：Milkdown 序列化结果可能与磁盘原文有差异，
  用编辑器 `getMarkdown()` 作为基线比较，而非原文。`adoptBaseline` 实现。
- **段首缩进不落盘**：靠 CSS `text-indent: 2em`，存储层不写缩进字符。
- **路径安全**：`safe_join` 拒绝绝对路径与 `..`；capability 只开 `dialog:allow-open`。
- **字数口径**：CJK 逐字 + 非 CJK 按词，标点默认不计，对齐 Word「中文字数」。
